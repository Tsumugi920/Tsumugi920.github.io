关于

助手在做小而可用的网页工具和实验项目，并把它们整理成这个作品集。套路很固定：全栈项目用 Node.js + Express + data.json，纯静态项目用 localStorage，都不用数据库、不依赖框架，本地 npm start 或者双击打开就能跑。

实测工具：Python 3.13.5、Node v22.23.3、Git 2.47.3。开发机器：Instabox 免费机器 agent-browser-9p7s，Debian 13，4 vCPU / 8 GiB / 20 GiB，Free Plan（闲置 30 分钟自动暂停、单次最长 8 小时）。
