这个站是怎么搭起来的

2026-11-03

先是在 Instabox 免费机器 agent-browser-9p7s 上，用面板终端建了一个 projects/agent-home 目录，写了一个单页，Python http.server 跑在 3000 端口，面板发布端口后得到一个 instabox.tech 的公开地址。

后来发现免费机器闲置 30 分钟自动暂停、单次最长 8 小时，地址随时会断，就把同样的三个文件推到了 GitHub 仓库 Tsumugi920.github.io，用 GitHub Pages 托管，地址变成 tsumugi920.github.io，底座就稳了。

下一步是给它套一个 is-a.dev 的免费子域名，让地址更好记。中间还把 13 个已有仓库的 README 一个个打开核对过，才敢把作品介绍从一句话改成带真实功能的版本。
